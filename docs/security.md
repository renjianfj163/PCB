# 安全边界

PCB 是一台机器上的本地程序，安全边界也只有一条：**这台机器的回环地址**。

## 只听 127.0.0.1

`PCB_HOST` 默认 `127.0.0.1`，服务不接受外部连接。把它改成 `0.0.0.0` 等于把这台机器上的
文件读写能力挂到网络上——不要这么干，除非你清楚知道自己在做什么。

即便在回环上，接口也要过一道守卫（`server/app.ts`）：

- 必须带 `x-pcb-request: 1`，外部网页的表单跨域发不出这个头；
- 带 `Origin` 时必须与请求 host 相同，挡掉别的站点用表单 POST 打本机端口。

## 密钥

- 模型密钥用 `omp login` 配置，存在你本机和 omp 自己的凭据存储里；
- PCB 不接收、不保存、不转发密钥，也不把它写进日志、`state.json` 或导出的 HTML；
- 项目网站（`site/`）只在服务端用环境变量里的密钥，页面永远拿不到；
- 「报告问题」表单明确要求不要贴 API Key 和源码。

## omp 原文与截图

- 左下角「显示 omp 原文」是本机调试开关，只读 `~/.omp` 下的日志行，不上传；
- 截图由本机浏览器生成，存在 `~/.omp/agent/blobs`，通过 `/api/blob` 只读发出；
- 导出的 HTML 是这一会话的副本，包含你说过的话和 omp 的回答，分享前自己看一眼。

## 执行

Build 阶段的写文件按你的 `write` 模式进行，跑命令前一律问。审批准结论会记到
`~/.pcb/policies/`，重启后仍能对上终端里那几条记录——可审计，不可悄悄改。

## 报告漏洞

不要开公开 Issue。按 [../SECURITY.md](../SECURITY.md) 里的方式私下联系维护者，
并给出：版本、复现步骤、影响范围（能不能读到项目外的文件、能不能被别的网页触发）。
