# 常见问题

**它跑在哪里？**
跑在你自己的电脑上。默认只监听 `127.0.0.1`，别的机器连不进来。对话、计划、改文件都由你本机的
`omp` 完成；项目网站（`site/`）只在旁边介绍，不参与运行，也不托管你的项目。

**为什么要 omp？PCB 自己不能想吗？**
不能。PCB 是基于 Oh My Pi 的工作平台，不是另一套模型：它把 omp 的 RPC 帧翻译成界面、按阶段拦住危险操作、把计划变成一次可点的批准。没有 `omp` 时它能启动，但发不出消息、执行不了计划，而且会直说这件事。安装包带 omp，源码方式自己装。

**密钥会不会上传？**
不会。密钥用 `omp login` 存在你本机，PCB 只在本机用它。项目网站不接收、不保存、不转发密钥，也不需要
注册或登录。

**它会自己动手吗？**
取决于阶段。Chat 只回答，Plan 只读并给计划，Build 才写文件；跑命令前一定问你。唯一的强门是右栏
计划页的「按这个做」——你点了才切到执行。

**改错了能还原吗？**
能。写文件是直接落盘的，但 omp-ckpt 会在回合前留检查点，回合结束后右栏「文件」页列出每个改动，
可以逐块接受或还原；编辑器里也有同样的 Keep / Revert。审查服务由 omp 宿主扩展提供，PCB 只连它。

**会不会偷偷联网？**
对话走你本机已登录的 omp。PCB 自己会联网的，是你让它打开的网页预览。它不下载编辑器。

**一定要打开 VS Code 或 Cursor 吗？**
不一定。一个软件包就够用：不写代码就留在 PCB 里对话、计划和改文件。想检查代码时，顶栏「IDE」打开你本机已安装的桌面版 VS Code 或 Cursor，并使用 omp-ckpt，工作区是当前项目。不附带、也不下载网页版 VS Code。打开后不是带地址栏的浏览器。

**OMP-ckpt 是什么？**
AI 连续改文件时的检查点。它保留修改前后的状态，方便看差异，也可以按块恢复。审查服务由 omp 宿主扩展提供，PCB 只连它。

**演示、发布和支付现在有吗？**
没有。产品演示 Skill、社交推广和支付接口在路线图上，网站会标明「规划中」。现在不能自动发布，也不能收款。

**关掉窗口是不是就没了？**
服务可以留在托盘继续跑：每天的定时任务挂在那个进程上，错过的一次不补跑。要彻底退出就从托盘里退。

**支持 macOS / Linux 吗？**
现在以 Windows 为先（系统文件夹对话框、编辑器查找、安装包）。源码方式在别的系统上能跑起来，但没有
安装包，也没测过。

**怎么报告问题？**
用网站上的「报告问题」，会在 GitHub 上开一条 Issue；或者直接在本仓库开 Issue。别贴 API Key 和源码。
安全问题按 [SECURITY.md](../SECURITY.md) 走。
