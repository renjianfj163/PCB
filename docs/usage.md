# 使用

PCB 的界面是三栏：左边项目与对话，中间是你说的话和 omp 的回话，右栏是文件、计划、终端、浏览器
四页。整页不滚动，中间和右栏各自滚。

## 先说清楚三个词：Chat · Plan · Build

界面底部输入框右边有一个下拉，它决定**下一条消息**按哪种方式处理。切换它不会自动发送，只影响
你接下来按下的那一句。

| 阶段 | 中文 | 它碰不碰你的文件 | 产出 |
| --- | --- | --- | --- |
| `chat` | 聊天 | 不碰。不改文件、不跑命令，只回答 | 一段话 |
| `plan` | 规划 | 只读。可以列目录、读文件，写和执行一律被拒 | 一份可以照着做的计划 + 一个「按这个做」 |
| `build` | 执行 | 会碰。写文件直接进行，跑命令前会问你 | 磁盘上的改动 + 逐块审查 |

三条实战建议：

- **先 Plan 再 Build**。计划留在右栏「计划」页，你看完点「按这个做」才切到执行；不满意就继续说，
  别切阶段。
- **不确定就停在 Chat**。问「这段报错什么意思」「有没有别的做法」在 Chat 里问，它读不到你的文件，
  但会给你判断依据。
- **Build 里写文件不需要点确认，跑命令需要**。写完后右栏「文件」页列出改动，可以在编辑器里逐块
  接受或还原。

## 第一次用

1. 左侧选一个项目文件夹，或点「添加项目」用 Windows 文件夹对话框挑一个。
2. 中间是空首页：「想做什么？」加一张白卡片。Enter 发送，Shift+Enter 换行。
3. 第一次发送才创建会话，并把这句话发给 omp；没选项目时发送按钮不可用。

会话就是项目里的一个对话。同一个项目可以有很多个会话，左侧列表按最近使用排序；「恢复会话」会把
历史约十几秒回放出来，期间显示「正在载入这段对话…」。回合进行中再发消息会排队，不会报错。

## 右栏四页

| 页 | 内容 |
| --- | --- |
| 文件 | 当前项目的目录树与只读预览；路径锁死在项目根内 |
| 计划 | Plan 阶段产出的计划原文，底部是「按这个做」 |
| 终端 | 命令输出；需要你同意的命令会在这里等你 |
| 浏览器 | 预览本机网页，可截图回填到对话 |

## 批准：唯一的强门

真正决定「能不能动手」的只有一处：右栏计划页的「按这个做」。它切到 Build 并把这份计划发出去。
其余情况里，危险操作会变成一张需要你点的卡片；取消就是取消，不会悄悄拒绝或悄悄同意。

## 顶栏的 IDE 按钮

只有编程版有这个按钮。点它打开本机已安装的桌面版 VS Code 或 Cursor，工作区是当前项目，
并装一次 omp-ckpt。两边都找不到时只回一行「本机没有 VS Code 或 Cursor」，不下载、不安装编辑器，也不启动网页版。
omp 仍是 PCB 已经拉起的那个进程。

## 托盘与定时

窗口关掉后服务可以留在托盘继续跑，因为每天的定时任务挂在这个进程上：错过的那一次**不补跑**，
下个时间点照常触发。

## 花费与上下文

输入卡片左下角显示 `上下文 N%` 和 `已花费 $x.xxxx`。金额取自 omp 自己的 `get_session_stats`，
不是界面估算；单位是美元原值。

## 键盘

| 键 | 作用 |
| --- | --- |
| Enter / Shift+Enter | 发送 / 换行 |
| Ctrl+K | 搜索对话 |
