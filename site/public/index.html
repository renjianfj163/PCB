HOW IT WORKS

从一个想法开始，逐步做出自己的产品。

PCB 把 AI 对话、任务计划和电脑上的实际操作放在一起，让你更容易使用 AI 开发软件。

PCB 不会重新开发一套 AI。它使用 Oh My Pi（OMP）来完成真正的 AI 工作，自己则负责提供操作界面、管理工作步骤和帮助用户检查修改。

  1. Chat

    对话

    告诉 AI 你想做什么。

    你可以像聊天一样告诉 AI 自己的想法。

    例如：

    • 我想做一个记账软件。
    • 我想开发一个简单的小游戏。
    • 帮我分析这个软件应该有哪些功能。
    • 帮我看看这段代码有什么问题。

    这个阶段可以自由讨论和修改想法，不会直接改变项目文件。

  2. Plan

    计划

    先让 AI 想清楚怎么做。

    AI 会了解你的项目，分析你的要求，并列出准备完成的工作。你可以先检查计划，看看 AI 是否理解了你的想法。只有你同意之后，才进入实际开发。

  3. Build

    开发

    让 AI 开始制作你的产品。

    确认计划后，OMP 就会在你的电脑上开始工作。它可以编写代码、修改文件和使用需要的开发工具。在重要操作中，你仍然可以进行确认和授权。

  4. Review

    检查

    检查 AI 做了什么，确认结果是否正确。

    你可以查看 AI 修改了哪些文件，检查修改内容。如果结果符合要求，可以接受修改；如果不符合要求，也可以恢复之前的版本。

Review 是开发过程中的检查步骤，不是另一套独立的 AI 系统。

FAQ

关于 PCB，你可能想知道这些问题。

PCB 是什么？

PCB 是一款运行在自己电脑上的 AI 编程工具。

即使你不会写代码，也可以用普通语言告诉 AI 你想做什么。PCB 帮助你讨论想法、制定计划，并让 AI 在电脑上完成实际开发工作。

PCB 和 Oh My Pi（OMP）有什么关系？

可以简单理解为：

  • OMP 是负责思考和执行工作的 AI 引擎。
  • PCB 是你使用这套 AI 系统的操作界面。

OMP 负责理解要求、制定计划和修改代码。PCB 负责让整个过程更容易操作和检查。

必须安装 VS Code 或 Cursor 吗？

不需要。

PCB 可以独立使用。

如果你以后想进行更深入的编程，也可以打开电脑上已经安装的 VS Code 或 Cursor。

AI 会自动修改我的文件吗？

普通聊天不会修改项目文件。

在开始实际开发之前，你需要先检查并同意 AI 制定的计划。某些需要特别授权的操作，也会要求你再次确认。

如果 AI 修改错了怎么办？

你可以检查 AI 修改过的文件。

对于重要项目，建议使用 Git 等版本管理工具保存不同版本。这样，当修改结果不符合预期时，就可以回到之前的版本。

我的项目会上传到 PCB 网站吗？

不会。PCB 网站不负责保存或运行你的项目，项目文件的操作都在自己的电脑上完成。

但需要注意：当你使用 AI 模型时，完成任务所需要的部分项目内容可能会发送给你选择的 AI 模型服务商。具体取决于你使用的模型和设置。

现在可以用 PCB 推广产品或收钱吗？

目前还不可以。

产品演示工具、社交媒体推广和支付功能都属于未来计划，尚未正式提供。

遇到问题，如何反馈？

你可以在 GitHub 上提交问题。

请尽量说明：

  • 你使用的是哪个 PCB 版本。
  • 你的电脑系统是什么。
  • 你进行了什么操作。
  • 出现了什么问题。

请不要在反馈中公开 API Key、密码或其他重要信息。
