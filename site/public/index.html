HOW IT WORKS

从一个想法开始，逐步把它变成产品。

PCB 将自然语言交互、AI 任务规划和本地执行整合在一个工作空间中。

PCB 不自己实现另一套 AI Agent。OMP 负责真正的 AI 工作，PCB 负责让这个过程更直观、更容易控制。

  1. Chat

    对话

    把你的想法告诉 AI。

    通过自然语言提出需求、讨论产品构思、分析问题、解释代码和探索解决方案。普通对话不会修改项目文件。

  2. Plan

    规划

    让 AI 理解项目，制定实施方案。

    OMP 可以读取项目上下文、分析需求，并形成具体的任务计划。你可以先检查计划，再决定是否批准执行。

  3. Build

    实现

    让想法真正变成代码和产品。

    批准计划后，OMP 在本机执行任务、修改文件、调用相关工具。执行过程中，用户仍然掌握必要的授权和审查权。

  4. Review

    审查 Build 环节

    检查修改，确认结果。

    查看实际文件变化，根据需要接受修改或恢复之前的状态。

Review 是 Build 工作流程中的审查环节，不是与 Chat、Plan、Build 并列的另一套 AI 引擎。

IDE · OMP · OMP-CKPT

不只是使用 AI，更是与 AI 一起开发。

对于需要深入开发的用户，PCB 可以直接打开本机已有的桌面版 VS Code 或 Cursor。

在熟悉的 IDE 中，结合 OMP 和 OMP-ckpt，完成代码编写、AI 修改、差异检查和项目恢复。

OMP-CKPT

让 AI 修改代码的每一步，都更容易检查和恢复。

AI 可以快速修改大量代码，但开发者需要知道项目发生了什么变化，并在修改不符合预期时保留恢复的能力。OMP-ckpt 为 OMP 辅助开发提供检查点管理。

  • Checkpoints · 检查点

    在开发过程中的关键节点保存项目状态，为后续恢复提供依据。

  • Project History · 项目状态记录

    保留不同开发阶段的检查点，帮助开发者管理连续修改过程。

  • Restore · 状态恢复

    当 AI 修改导致问题时，可以利用之前保存的检查点恢复项目状态。

  • Non-Git Project Support · 非 Git 项目

    不要求用户必须先建立 Git 仓库，也可以使用检查点机制。

  • IDE Workflow · IDE 协同

    与 VS Code、Cursor 等桌面开发环境配合，让开发者在熟悉的 IDE 中检查 AI 的修改结果。

OMP-ckpt 是项目状态保护与恢复工具，不是 Git 的替代品，也不是另一个 AI Agent。检查点的实现方式、恢复粒度和文件排除规则以当前代码为准。

ONE WORKSPACE

一个 PCB，适合不同的工作方式。

PCB 只有一个统一的软件包。不熟悉代码的用户，可以直接通过自然语言与 AI 协作；熟悉代码的用户，可以打开本机已有的 VS Code 或 Cursor，进一步检查、修改和开发。

PRODUCT JOURNEY

从创意到产品，从产品到市场。

PCB 的目标不只是帮助用户开发软件，还希望逐步打通产品演示、内容传播和商业化流程。

  1. 可用

    Chat

    对话 · Explore Ideas

    用自然语言提出想法，讨论需求，探索可能性。

  2. 可用

    Plan

    规划 · Plan & Design

    让 AI 理解需求、分析项目并制定实施计划。

  3. 可用

FAQ

关于 PCB，你需要了解的事情。

它是什么、和 OMP 的关系，以及哪些能力已经提供、哪些还在规划中。

PCB 是什么？

PCB 是一个基于 Oh My Pi 构建和扩展的本地 AI 工作平台，帮助用户通过自然语言交互、任务规划和本地执行完成工作，并逐步扩展产品创建、推广和商业化能力。

PCB 和 Oh My Pi 是什么关系？

OMP 是 AI 执行引擎，负责对话、计划和文件修改。PCB 提供更友好的图形界面、工作流程和安全控制。PCB 不重新实现一套 Agent。

OMP-ckpt 做什么？

OMP-ckpt 为 AI 辅助开发提供检查点管理和项目状态恢复能力，帮助开发者查看和管理 AI 连续修改项目带来的变化。

一定要安装 VS Code 或 Cursor 吗？

不需要。PCB 可以独立使用。需要深入开发时，可以选择打开本机已有的 VS Code 或 Cursor。

AI 会自动修改我的文件吗？

普通聊天不会修改项目。进入 Build 阶段需要明确批准计划，运行需要确认的命令时还会进行额外授权。

修改出错怎么办？

可以通过 OMP-ckpt 检查点恢复之前保存的项目状态。重要项目仍建议同时使用 Git 等版本控制工具。

项目文件会上传到 PCB 的网站吗？

PCB 官网不承担用户项目的云端存储和执行。PCB 的项目操作在本地进行。但执行 AI 任务时，发送给模型服务的上下文可能会传输到相应模型服务商，具体取决于使用的模型和配置。

演示、推广和支付现在能用吗？

目前属于未来规划。产品演示 Skill、社交推广和支付接口尚未正式提供。
