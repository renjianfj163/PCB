给不写代码的人用的本地程序

你用中文说明想做什么，本机的 omp 负责对话、做计划、改文件。它跑在你自己的电脑上， 默认只听 127.0.0.1——别的机器连不进来。

  • 动手前先拦一下：界面拦住危险操作，并把计划变成可以点的「按这个做」。
  • 三个阶段：规划只读；执行时改文件、跑命令前会问；聊天只回答。
  • 编辑器：顶栏可以打开只绑本机的 VS Code 网页版，工作区就是当前项目。
  • 密钥留在本机：模型密钥用 omp login 配置，这个网站不接收、不保存。
  • 想写代码：点下面「下载与版本」把安装包装到本机；网站不替用户写代码。
  • 发现问题：用本页「报告问题」那张表，会在 GitHub 上开一条 Issue。

安装和系统文件夹选择以 Windows 为先。
